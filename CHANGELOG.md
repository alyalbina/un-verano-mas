# Changelog

## 0.8.0 — The Open Road

- Added the frame-repair workshop, belt transmission and reversible mechanical experiments.
- Added Zhorik's thread-and-belt interaction and Tadeo's workshop notes.
- Connected the repaired frame to a physical village map in the loggia.
- Added departure dialogue with Carmen and the real harbor as the first chapter's ending.
- Extended persistence to schema 7, preserving migration from v0.7, v0.6 and v0.5.
- Preserved the three-screen courtyard, street and plaza.
- Converted artwork to lossless WebP for a smaller delivery.

## 0.7.0 — Panoramic Journey

- Expanded courtyard, street and plaza to 3840 pixels each.
- Added a following camera, distant exploration and per-location position saves.
- Added six optional observations and companion following in the expanded spaces.

## 0.6.0 — Water and Echo

- Added the reflection street and the plaza with a musical fountain.
- Made the two puzzles playable in either order.
- Added reversible inventory placement, visual rhythm feedback and a shared narrative consequence.

## 0.5.0 — The Photograph

- Introduced the photographic doorway, light-and-shadow puzzle and hidden loggia.
- Established the current narrative direction and progression state.

## Repository edition

- Added this project to GitHub with a visual English README, a Russian quick start and a concise design case study.
- Kept the playable v0.8 game logic, original design history, artwork provenance and validation records.
