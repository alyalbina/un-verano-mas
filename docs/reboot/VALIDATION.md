# Проверка v0.7: широкие локации

Проверено в Godot 4.5.1, Linux, Compatibility/OpenGL, Mesa llvmpipe. Использованы реальные события Input, графические кадры и файловые операции.

| Сценарий | Результат |
| --- | --- |
| reboot_rules.gd | 40/40 |
| reboot_playthrough.gd | 42/42 |
| reboot_startup.gd | 8/8 |
| episode_rules.gd | 55/55 |
| episode_playthrough.gd | 39/39 |
| episode_startup.gd | 14/14 |
| panorama_rules.gd | 24/24 |
| panorama_playthrough.gd | 28/28 |

Всего **250 уникальных проверок** текущей версии. Новые проверки координат и прогулок (24 + 28) повторены из чистого архива после нового импорта. Все рисунки и сценарии загрузились; ошибок ресурсов и GDScript нет. Предупреждение VSync относится к виртуальному дисплею.

Новая проверка действительно проходит на обе стороны всех трёх широких локаций через кнопки и удержание клавиши. Проверяет края камеры и навигации, сохранение размера Лусии, неподвижный HUD, клики по удалённым объектам, шесть новых записей, сопровождение кота, паузу/модальные окна, диск и восстановление удалённой позиции, сброс камеры в кухне и работоспособность старого предмета. Проверка состояния отвергает некорректные координаты атомарно и принимает старое сохранение без словаря позиций.

Просмотрены шесть кадров дополнительных участков и три момента видео: начало, центральная улица, дальний берег. Оформление стыков отдельно проверено после изменения рисованных пилястр. Видео — настоящая запись работающего Godot; для демонстрации использовано состояние после вступления. Оно не выдаётся за прохождение с нуля или тест с людьми.

Длительность и интерес с внешними игроками не измерялись. Windows EXE не экспортировался; поставляется исходный проект Godot. Кухня и лоджия остаются камерными, C04 и C05 пока не реализованы. Сопровождение кота использует существующие позы, без нового художественного цикла ходьбы.

## Повторить

Два новых сценария:

```
godot --headless --path PROJECT --script res://tests/panorama_rules.gd
godot --path PROJECT --script res://tests/panorama_playthrough.gd -- --qa
```

Остальные шесть запускаются так же, как описано для v0.6. Playthrough-сценарии требуют графического дисплея и --qa; startup-сценарии используют отдельные qa-файлы и запускаются без --qa. Демо panorama_demo_live.gd требует --qa и отказывается запускаться без него.
