# Происхождение материалов v0.5

Сохранён утверждённый художественный референс `assets/art/source/approved_reference.png` и исходный персонажный дизайн. Старые ресурсы, Character, Audio и логика интерфейса переиспользованы из v0.4.

Новые PNG созданы генерацией изображений по этим референсам: courtyard, courtyard_clear, passage, photograph, lucia_photo, zhorik_pounce, archive_photo. В lucia_photo исправлена миниатюра снимка, чтобы она показывала двор с дверью. В courtyard_clear убрано только полотенце. PNG не перерисовывались программно. `regions.json` содержит границы альфа-силуэтов для AtlasTexture, без изменения рисунков.

Реальное изменение сцены создаётся состоянием Godot. Проекция, солнечный блик, поворотная доска, тень соединения, рябь и интерфейс рисуются нативным кодом. Архитектурные схемы SVG/PNG созданы из точных связей вручную, без imagegen. Игровые кадры — реальные снимки Viewport Godot.

Эффекты WAV и фоновые петли переиспользованы из прежнего проекта; они синтезированы для прототипа. Коммерческий звук, полная анимация, лицензирование финального набора и проверка фотографий для публичного выпуска входят в backlog. Ассеты из Lost in Play и остальных референсов не использованы.


## Добавления v0.6

`street.png` и `plaza.png` — новые изображения, созданные встроенной генерацией по стилистическому референсу дворика. `street_open.png` — локальная вариация той же улицы с открытой аркой. Генерации: b3a7ec1c-24ea-4a04-a6f9-866879872342, d079deb0-1afe-4c7e-aa60-92ef931e89b6, 0369632e-c98e-4bd0-a236-84e332a5f540.

Рычаг, кувшин, зеркало, вода, сколы, трубки, клапаны, ленты, волны и увеличенное отражение рисует Godot. Это функциональная геометрия, а не сгенерированная картинка решения. Гитарист находится в рисунке площади; отдельная анимация руки пока не реализована.

`guitar_motif.wav` — оригинальный синтез plucked-string/Karplus–Strong, три небольшие фразы, без заимствованной композиции или записи. Это рабочий звук, не финальная музыкальная аранжировка.

## v0.8 — мастерская и гавань

Два новых фона созданы встроенной генерацией изображений 14 октября 2026: `workshop` — exec-74c92973-684c-4cd2-849b-329516a01d24; `harbor` — exec-e60a1cd4-5e02-45de-95f3-646e77932ac9. Это вымышленные места по художественной концепции проекта; гавань не выдаётся за точное место на личной фотографии. Промпты: ASSET_PROMPTS_V0_8.md. Передача, обратный вид, карта, стрелка и проверки связности — точная интерактивная геометрия Godot, не часть сгенерированного фона. Фотографии пользователя не включались в новые генерации.

В сборке v0.8 рисунки поставляются как lossless WebP: все пиксели и альфа проверены против PNG. Это смена формата без перерисовки и без изменения размера; она уменьшает архив для скачивания.
