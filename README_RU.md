# Un Verano Más — v0.8 · The Open Road

Нативное приключение на Godot 4.x: тёплая Испания, странные промежутки между фотографиями и настоящее путешествие к морю.

## Запуск

1. Склонируй репозиторий или скачай Code → Download ZIP и полностью распакуй его.
2. В Godot нажми «Импорт» и выбери `project.godot` в корне репозитория.
3. Дождись импорта рисунков и звука, нажми **F5**.

Это исходный проект, не Windows EXE. Проверен в Godot 4.5.1 на Linux. Windows отдельно не тестировалась. Никакие API-ключи и платные сервисы для запуска не нужны.

## Что можно пройти

Первая глава: **дворик → кухня → скрытая лоджия → улица / площадь → мастерская → карта в лоджии → гавань**. Семь доступных локаций, пять основных головоломок. Улицу и площадь можно решать в любом порядке; мастерскую можно исследовать после открытия арки.

В v0.8 добавлены ременная передача и обратный ход рамы, помощь Жорика у ниши, журнал Тадео, привязка пути к настоящей карте, сборы с Кармен и вечерняя гавань. Осмотр катамарана и мороженого сохраняет отсылки к вашей поездке. Гавань завершает первую главу; игровая морская поездка и остальные города ещё в разработке.

Дворик, улица и площадь сохраняют ширину **3840 пикселей — три экрана**. Камера плавно следует за игроком. Масштаб персонажей не изменён. Мастерская, лоджия, кухня и гавань — камерные комнаты. Свободное исследование после решений остаётся доступным.

## Управление

ЛКМ — идти и исследовать. Предмет выбрать в сумке, затем нажать на объект. Перетаскивание — снимок, доска, блик, установленное зеркало и стрелка на карте. ‹ / › и клавиши ← / → — гулять по панорамам. H — помощь, N — блокнот, T — карта, A — альбом, I — сумка, M — звук, Esc — пауза. Подсказки выдаются в три ступени только по запросу.

## Сохранение

`user://photograph_v0_8.json`. Без нового сохранения переносится v0.7, затем v0.6 или v0.5; оригинал не меняется. В Windows файл обычно находится в `%APPDATA%/UnVeranoMas/`. Частичные эксперименты и позиции сохраняются, запись атомарная. «Начать заново» в паузе сбрасывает только текущую версию.
